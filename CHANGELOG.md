# Changelog

## 1.0.0 — 2026-11-20

Первый неформальный релиз «Java-тесты для Study Hub»: тренажёр для подготовки к собеседованию по
Java, который работает локально в Docker.

- Банк вопросов Java Core с эталонными ответами: «Основы языка» (36 уроков, 181 вопрос) и
  «Особенности внутренней работы Java» (15 уроков, 86 вопросов).
- Навигация курс → тема → урок с числом вопросов. Страницы разделов показывают ссылочные хлебные
  крошки и банк вопросов.
- Тестирование мастером: 10, 20, 50 или все случайные вопросы, 2 минуты на вопрос, «Показать ответ»
  с отметкой «Ответ просмотрен», сброс «Не сдан» по таймеру.
- Результат для ИИ-агента в двух вариантах, полном и упрощенном. Каждый вариант — пара файлов .md и
  .json с датой и временем сдачи в имени.
- «Моя история тестирования»: все попытки хранятся в PostgreSQL, строка раскрывается в вопросы и
  ответы, результаты можно скачать заново, тест можно удалить.
- «Справка по использованию» на основе README.
- Светлая и тёмная тема.
- Полная пересборка приложения скриптами `scripts/rebuild.*` для Windows, macOS и Linux.
